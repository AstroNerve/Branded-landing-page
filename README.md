# AstroChips standalone landing page

## Run locally
Open `index.html` in a modern browser. For best video playback, serve this folder over a local web server (for example, VS Code Live Server) because some browsers restrict media when opened as a local file.

## Deploy
Upload the contents of `standalone/` to any static host. Keep `assets/` beside `index.html`.

## Video
The supplied video is included as `assets/astrochips-hero.mp4`. The hero video is configured with `autoplay muted loop playsinline`; sound is off by default to support browser autoplay policies.

## Customise
- Replace `assets/astrochips-hero.mp4` to change the hero loop.
- Replace `assets/astrochips-product.png` to change the product image.
- Update contact details and any product claims before publishing. The email address is a placeholder.
